用例 03

产线设备能耗数据我拉了一个月的,节能改造立项要用,做几页PPT。核心发现是1号线的单位产品能耗0.85kWh/件,远高于其他产线的0.5左右,排查下来主要是1号线的液压系统老化导致效率下降,这个要单独拎出来算一笔账:如果更换液压系统投入约120万,按当前产量和电价,大概18个月能收回成本,这笔账要在PPT里算清楚。另外3号线虽然单位能耗不高0.48,但空载能耗偏高,待机状态下每小时还跑12kWh,说明停机流程不规范,这块也要提一句。整体结构上先把四条线的能耗对比摆出来,再聚焦1号线做深挖,最后落到节能改造的投资回报测算。

产线。数据对齐。

/ 月产量(万件) / 月用电(万kWh) / 单位能耗(kWh/件) / 空载能耗(kWh/h)
1号线 / 80 / 68 / 0.85 / 8
2号线 / 95 / 49 / 0.52 / 6
3号线 / 70 / 34 / 0.48 / 12
4号线 / 60 / 31 / 0.52 / 5

工业电价0.75元/kWh,节能改造的ROI按此计算。行业标杆单位能耗约0.45kWh/件。

用例 06

老旧小区改造工作汇报的PPT，几条硬杠杠，是给政府评审组看的,纲目我列好了,你按公文口径给我填实、填规范:

#1 改造任务完成情况
#2 资金使用情况
#3 居民满意度
#4 存在问题
#5 下一步计划

每个小标题下面的内容要对得上标题本身,不要出现文不对题、内容混装的情况;数据类的表述(比如完工率、资金到位率、满意度这些)前后要统一口径,不能一会儿百分比一会儿又是笼统说法。存在问题那部分不要写虚的,要能看出跟前面资金和满意度两块是呼应的、有对应关系的,评审组一眼要能看出问题是从哪儿来的。小标题的措辞要正、要像公文里出来的,不要用口语化的说法。

用例 10

明天一早管理层要碰这个事，得今天出，今晚得把PPT攒出来。手上三块料:舆情监测那边出的负面话题摘要、这三天客服来电统计的要点、还有公关部连夜赶的声明草稿,这三样不能直接拼在一起糊弄,得融合成一个完整的危机应对逻辑给到管理层。

结构上我想清楚了,事实时间线要先立住,然后是影响评估,声明草稿这块要单独拎出来给修改建议,分级响应机制也得有,这四块都不能少。

素材一·舆情摘要：6月10日起某测评博主发视频质疑我们产品有安全隐患,视频发布后24小时内转发破万,评论区负面情绪占比约72%,话题主要集中在“是否虚标”和“售后甩锅”这两个点上,目前情绪是质疑为主,还没有权威媒体跟进,但已有3个垂类KOL开始转发,有进一步发酵的苗头,这个时间窗口很关键,48小时内如果不做有效回应,可能从质疑升级为抵制。

素材二·客服来电要点：近三天相关来电大概40通,诉求集中在退货退款(约60%)和要官方说明(约35%),注意有部分用户是直接引用了那条视频的说法打进来的,说明视频的传播已经影响到实际客诉了;另外电商渠道的退单量也比平时多了约15%,需要纳入影响评估。

素材三·声明草稿：草稿写的是“我司产品均符合国家标准,视频内容与事实不符,我司保留追究法律责任的权利”,但内部备注里技术复核还没做完,预计还需要36小时才能出结论;在这个节骨眼上把话说得这么满,万一复核发现确有问题会非常被动;另外“追究法律责任”这种强硬措辞在当前情绪下很可能被解读为店大欺客、激化对立,这两点务必在修改建议里体现出来,不是随便改改措辞就行。
