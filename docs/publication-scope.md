# GitHub 发布范围

本仓库发布可运行研究代码与必要文档，未将历史实验数据集作为公共数据集发布。

| 上传 | 用途 |
|---|---|
| `ppt_rubric/`、`pyproject.toml` | 安装、构建、审核、渲染、评分、报告、导出与历史协议兼容 |
| `configs/*.json` | 不含密钥的可移植配置；当前入口是 `contract-v2-*` |
| `tests/`、`fixtures/` | 离线回归测试及最小故障样例；fixture 中的片段不是完整评测集 |
| `docs/`、`README.md` | 方案概览、完整 prompt 说明、快速开始、架构、评测方法、历史结果与已知限制 |
| `.agents/skills/ppt-rubric-generator/` | 可选的 Codex 项目工作流说明 |
| `examples/`、`.github/workflows/` | 无密钥离线示例与持续测试 |

不上传 `data/`（原始PPT、任务集及人工标注）、`artifacts/`（API请求/响应、缓存、各轮授权与实验输出）、`.cache/`、`.venv/`、`research/` 第三方副本、凭据、`configs/local/` 本机配置，以及含本机授权历史的根 `AGENTS.md`。这些文件继续保留在原开发机，不因发布而删除。

方案概览完整保留真实用例讲解、评分表及提示词。历史文档中的 `data/`、`artifacts/` 路径用于说明实验来源，不代表 clone 后包含这些记录。公开文档提供历史结论与限制；没有原始实验材料时，不能独立复算文档中的历史分数。来源片段及最小回归样例只用于解释方法和验证软件行为。

公开配置中的本机渲染路径已替换为 `soffice`；原配置在原开发机 `configs/local/` 备份。发布版本新增按供应商环境变量读取密钥与 PATH 查找渲染器，不改变评分标准。历史验证数字仍属于当时的冻结版本，不能当作本次发布后的线上重测。
