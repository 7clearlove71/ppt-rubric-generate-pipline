# GitHub 发布范围

2026-10-14，仓库所有者明确要求将本机后续开发需要的材料上传到现有公开仓库。仓库现包含源码、测试、文档，以及原始样本、人工标注、生成轨迹和历次实验记录，供新机直接 clone 后接续。

具体材料与迁移步骤见 [新机接续](new-machine.md)。`data/`、`artifacts/`、`.cache/api/`、`.cache/render/`、早期检查与字体诊断、`configs/local/`、`AGENTS.md` 和 `research/` 均作为本次历史快照纳入版本管理。第三方研究副本用于方法参考，来源信息保留于原文件及研究文档。人工标注不代表绝对真值，早期模型代评不作为人工标签。

不上传凭据、钥匙串、虚拟环境、安装包缓存、字体系统缓存、Python字节码、临时发布测试环境和操作系统杂项。`.gitignore` 继续阻止未来新增运行数据被无意公开；本次经所有者批准的文件已显式跟踪，修改会显示在 git status 中。新增实验产物须检查凭据后明确纳入版本控制。

历史实验文件保持原始字节、路径和哈希，不能为适配新机而批量改写旧账本或冻结配置。新机用迁移工具生成单独清单；原机器配置只供参考，实际运行使用当地渲染器和字体。凭据必须在新机配置，所有历史调用授权均已关闭。
