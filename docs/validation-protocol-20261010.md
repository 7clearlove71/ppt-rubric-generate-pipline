# 当前 pipeline 的人工一致率验证

日期：2026-10-10。目的：实际运行自动生成与审核，使用生成的同套 rubric 对候选逐条评分，再比较人工偏好。模型认可 rubric 本身不能代替这个实验。

## 本轮版本和范围

- 首先测当前生成策略：prompt `2026-09-30.8`、validator `6`，五维预算30/25/15/15/15，最多两轮自动修订；不因已知人工胜负修改本轮生成提示词或逐例权重。
- 本轮只使用开发用例01、02、03、05、06、09、10。留出04、07、08的人工正文未读取；最终生成/评分策略冻结后另行验证。
- 计划由百炼 Kimi-K3 生成、观察和审核，MaaS Kimi-K2.6逐条判定成品。二者是不同版本的同系列模型，不宣称消除了相关偏差。MaaS judge使用单并发、20秒最小间隔，复用已验证的限流策略。
- 运行目录：`artifacts/validation-20261010-v1/`。配置、来源清单、代码文件及提示词指纹保存在本轮快照中；后续改变生成或评分策略须另建版本，不覆盖本轮失败和分歧记录。

## 人工标签

使用 `import-labels` 从 `data/10_top_sample_20261010/<编号>/评测人_*.md` 导入。根据真实模型目录名和PPTX哈希转换评测人的 A/B 到冻结清单编号，不能直接抄写字母。理由保留原文及编号映射，不发送给生成器或judge。

开发集7例已导入，其中6例给出明确胜负或持平；09明确为“暂时无法判断”，保留为空，不根据理由推断胜负，也不计作平局。09仍可做模型评分，但不进入已确定人工标签的一致率分母。留出集标签不在本轮文件中。

## 报告与判定

1. 先报告生成通过数/7和失败原因。只有通过当前程序校验与模型审核的rubric进入完整judge；失败用例保留在报告中。
2. 每个候选必须完成全部条目。unknown或未完成时总分为null，不推断胜负。
3. 延续原协议：总分差绝对值不超过3分判为持平；超过3分取高分候选。人工平局与模型平局须精确匹配，不能算半个正确。
4. 同时报告一致率（匹配数/已完成且人工已决定的用例数）、评测覆盖率、匹配数/全部已决定标签数，以及逐例总分、分歧、Wilson 95%区间。部分通过不能宣称整体达到验收标准。
5. 暂以90%一致率作为工作目标，尚非用户明确批准的最终数值门槛。在当前6个已决定开发标签上，这意味着6/6；5/6仅为83.3%。开发通过后还须保持同一策略验证留出集，不能根据留出答案调参后仍称为首次留出验证。
6. 数字一致之外，抽查rubric覆盖和judge证据，区分生成漏项、重复/越权要求、判定错误、权重问题和渲染差异。人工记录本身有保留意见时同时保留，不用改写人工答案来提高一致率。

## 调用预算与执行门槛

离线预检7/7通过，候选共130页。生成冷缓存首轮49次逻辑调用，含最多两轮修订为91次，三次尝试的理论上界273次HTTP请求；这不是授权范围。

本轮拟申请百炼生成/审核合计最多120次实际请求（含重试、跨命令恢复），上限先到即停。MaaS成品judge按最多300次实际请求管理；实际需判定的条数在rubric生成后由离线计划给出。不得为塞入预算而删除rubric或跳过条目。

按上轮实测粗估：K3生成约80万—300万token，完整judge约600万—1200万token；受实际条数、页数、缓存和失败影响，不构成消费保证。价格未核实，不给金额估计。百炼旧30次授权已耗尽；本轮计划及配置文件本身不代表获批，须取得新的明确授权后执行。若恢复，先从120或300的总预算扣除对应目录已记录请求数。

```bash
python3 -m ppt_rubric import-labels --source data/10_top_sample_20261010 --out artifacts/validation-20261010-v1/human-labels-dev.json
python3 -m ppt_rubric plan --operation generate --config artifacts/validation-20261010-v1/generation-config.json --out artifacts/validation-20261010-v1/generation-plan.json
# 批量生成须先获明确授权；本文不提供自行确认授权的快捷命令。
# 生成后仅对合格rubric完整judge；以下compare保留未完成与人工未定项。
python3 -m ppt_rubric compare --labels artifacts/validation-20261010-v1/human-labels-dev.json --judgments artifacts/validation-20261010-v1/judgments --config artifacts/validation-20261010-v1/judge-config.json --out artifacts/validation-20261010-v1/agreement.json
```
