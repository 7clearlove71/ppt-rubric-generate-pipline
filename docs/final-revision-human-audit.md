## 结论及证据边界

现有标签适合作为七个具体任务的人工偏好记录，不足以作为已经验证可靠的“金标准”。每个用例只有一份人工记录，由两名评测者分案完成；没有同案独立复评，因此不能估计标注者间一致性，也不能从自动与人工不一致推出某方错误。模型目前同样存在可从记录直接定位的语义误判、视觉证据差异和重复扣分风险。

本审计读取人工 Markdown、对应 prompt、导入/比较代码和历史最终判定文件。对人工声称的 PPT 页面事实，除与 prompt、记录自身及旧模型结果交叉比较外，没有重新打开 PPT 或图像验证。下文“需核对”均不是已确认缺陷；旧模型理由也不是视觉真值。

当前开发集 Markdown 经 `import_markdown_labels` 重新导入，与 `artifacts/validation-20261013-evidence-v1/human-labels-dev.json` 完全一致。原始来源哈希、候选哈希和 A/B 映射校验通过。02、09 的人工 A/B 与 manifest A/B 相反，导入已正确转换；分析文字仍使用人工 A/B，必须保留映射。

| 未定 | 09 明确“暂时无法判断” | 即使理由偏向某候选，也不能从理由推断胜者或改记持平 |
| 重复评测/置信度 | 未记录同一评测者复评、盲法核验、统一置信度 | 无法计算重测稳定性或人工共识置信区间 |

现有 `evaluation.py` 将相同 rubric 的两份完整自动分数相减，差值绝对值不超过 3 分即平局。它正确保留了未定、未完成和覆盖率，但“人工整体选择”与“加权二元 checklist 分数”之间仍有构念差异。可以报告严格匹配率，不能把它单独解释成客观质量准确率。

## 逐案应如何解读

表内候选 A/B 均为 **manifest 编号**。

| 用例 | 人工标签 | 可核验的任务依据或记录事实 | 偏好、解释空间与待核查事项 |
|---|---|---|---|
| 01 | A | prompt 仅给三条团队进展；“团队已完成系统成果”是否超出材料可逐条核对。 | 哪种技术扩展会误导团队归属须读同页标题、来源和限定。信息密度不适合 20 分钟是场景评价，需要阅读时间/字号等证据，不能由字数直接推出。 |
| 02 | B | prompt 是“总投资 280 万”，并非“申请补助 280 万”；资金性质区分有明确来源依据。 | 将自动申报资格称为“措辞问题、修改量小”，而将另一错误判得更重，是重要性与修改成本判断。资金页是否重叠须在同一渲染上核对。 |
| 03 | tie | prompt 给 18 个月回本与行业标杆约 0.45，未给液压占比、老化损失率或改造后实测能耗。 | 由假设导出结果不自动构成“循环论证”；要看是否反用结论证明假设。A 的 0.45/0.5 也不是实测改造结果，不能把基础现状与改造目标合称“实测起点”。平局是两类问题影响相当的主观权衡。 |
| 05 | tie | prompt 明确“存疑的地方标出来，别下定论”，也明确“仿古街新修、老宅保护没钱投”，并把“文化记忆断层”等列为初步感受。 | 需区分复述已有观察、文学化标题、将待考口述升级为事实。把“钱修了古”单独视为无来源因果并不充分；需核对是否增加资金挪用或确定因果。7 页与 10 页优劣不是用户给定硬门槛。布局范围及严重程度要独立核实。 |
| 06 | B | prompt 没有原始数据；人工明确接受双方作为情景示例，重点评内部自洽与问题对应。 | 不同分母的百分比相减、“账面结余”推出“无实物工作量”等是适合核验的推理问题。推论成立还需同页完整上下文。人工以 PowerPoint PNG 判断无重叠，自动以 LibreOffice 图像判重叠，不能直接归因为人工漏看。 |
| 09 | 未定 | prompt 明确现金只够两个月工资、续约率 91%，没有危机持续时长、新老客户收入分解。 | 工资覆盖时长与危机时长、营收占比与增量比例、相关与因果的区别可核验。原记录正文方向性偏好与最终未定并存，应保留未定。材料本身已有“没有裁员/没有一个人退缩”，“一个都没少”须结合它们读，不能仅按净增人数判断。 |
| 10 | B | prompt 区分事件 48 小时窗口与“还需 36 小时”技术复核，明确未复核不能先断言。 | 原记录先称 B 的 `T+36` 与素材一致，又承认 B 同样混淆起点；这说明需要同尺度事实复核，不足以推翻总体选择。“唯一可自控变量”也须结合建议语境核查。 |

03 还有一个独立的数学核查点：若某量“高出正常值 29%”，消除超额的节省量相对于当前值通常为 `29/129`，不是 `29/100`。原人工记录引用的计算链使用 `30.6 × 29%`。只有查清页面实际把 29% 定义为“超额相对正常值”还是“可消除损失占当前值”后，才能判定算错。这是理由层面的复核点，不用来臆测或更改胜负。

## 模型结果不能借人工疑点免责

旧最终记录也显示应修 pipeline 本身，而非调整它以复现六个标签：

- **同一损害可能重复扣分。** 06/B 的 `R11`（可读性）和 `R12`（视觉层级）均以 P6/P7 的正文与红色对应标注叠印为主要失败证据，注册成不同 ID 后仍被一致性复核记为通过。ID 不同不等于独立缺陷；同一叠印引起的阅读困难不能仅换个维度名称重复计罚。
- **局部措辞会被升级为非等价事实。** 03 的 `R07`、`R10` 把标题/图表中的“120 万”“0.45”没重复“约”当作失败，即使同页其他位置给了限定。应该检验整段表达是否真的使读者获得更强事实承诺，而不是逐字复制源文限定。
- **有分数和复核通过不等于正确。** 05/B 最终 100 分与人工声称大范围视觉不可用冲突；06 的方向相反也可能同时涉及视觉输入差异和语义取舍。应定位具体失配的事实、判据和计分，不按胜负反推哪一方“应改”。
- **不可把缺失评分算作失败或持平。** 03、09 有未决项，10 受 HTTP 403/校验失败影响；这些是评测覆盖限制。

## 后续报告与人工复核规范

以下规范用于今后新增评测，不追认历史评测已经满足，也不阻塞本轮自动修订与验证。

1. **冻结两个目标。** 分开报告来源与需求支持的 rubric 有效性、逐项判断可靠性，以及自动结果与人工整体偏好的一致性。前两者是 pipeline 的直接质量目标，第三项为外部参照。
2. **固定观看产物。** 每案登记 PPTX、渲染 PDF/PNG 的哈希、渲染器版本、字体环境、分辨率和页数。人工与模型比较时使用同套图像；另报原生 PowerPoint 下的可用性，不混在同一视觉事实里。
3. **盲评并同案复评。** 隐藏模型身份和模型分数，随机化候选顺序；至少两名评测者独立完成同一案例，保留分歧，再按需要进行第三方裁决。不得用代理复写理由代替新的人类判断。
4. **先记证据再选偏好。** 每条问题标明页码/区域、来源片段、确切主张、严重程度及对任务的影响。区分事实错误、无依据推断、来源遗漏、视觉不可用、风格偏好。未知不补写成反面事实。
5. **区分三种非胜负。** “质量相当”“各有优缺点难以取舍”“信息不足无法判断”分别记录；只有预先指定的类别才能映射到 benchmark 的 tie。不得从理由推断选择。
6. **不回流人工标签。** 生成器、judge、独立评审模型均不接收人工胜负或人工理由。人工审计文档只用于比较解释；通用修复必须能由任务和独立证据证明，并有合成正反例验证。
7. **全面报告。** 给出明确标签数、评分完成数、经独立复核数、未决/基础设施失败数；逐案报告分歧类型。若调整权重或 tie 阈值，须在新验证前冻结，同时保留旧协议结果，不选最好的一版作唯一结果。

通用 comparison-only 可靠性元数据可记录 `reviewer_count`、`blindness`、`artifact_identity_verified`、`render_identity_verified`、`independent_review`、`tie_semantics`、`confidence`，未记录一律用 unknown，不从文风或结论推断。当前导入程序主动拒绝同案多文件，下一步若收集复评，应另建原始多评测者记录结构与显式裁决流程，不能静默选第一份或多数票覆盖历史记录。

## 冻结 v2.3 后的有界架构复盘

本段仅依据最终来源 QA、已完成部分的正式评分 QA、局部视觉 QA、冻结 v2.3 规范及 `rubric-granularity.json`，不新增版本、调用、评分或人工标签。正式评分 QA 仍在进行，以下引用具体已确认反例，不提前填完整覆盖率。

本轮已从结构上移除自由 DESIGN 的二次扩写、另写 judge prompt 的语义漂移、重抄来源原句的接口脆弱性，以及无图跨候选复核改判局部视觉证据的路径。来源 ID、确定性编译、版本与哈希绑定、逐页视觉聚合、分歧保留区间，使执行和复核边界更清楚；这些工程保障不能替代下述测量有效性。

1. **“一 Q 一 R”没有建立“一语义目标一责任”。** 程序保证每个 Q ID 恰好编译一次，且不会被下游自由扩写；但 Q 本身仍由模型划分，同一事实或限定可能被写进多个 Q，遗漏也可能在此发生。03 的 12kWh/h 共享事实、05 的待考状态、06 的公文文体都经过一对一编译后保留重复归属；10 的模块先后要求则在提取时丢失。七份最终 rubric 全获自动批准，而来源 QA 在四例确认五项问题，说明仍薄弱的是来源目标的语义分解与审核，不能用编译确定性为上游语义背书。
2. **固定维度预算固定了政策比例，没有校准扣分单位。** 30/25/15/15/15 防止随候选胜负调整维度总额，却仍按 Q 的数量、分类、重要性分配维度内权重。03 的整套 ROI 是一个 30 分二元项，06 没有专属 fact，因而 C_REASON 独占 25 分；同一通用 C_REASON 在09仅3.125分。单点与大范围缺陷还可能损失同一整项权重，视觉一处与多页遮挡也都只损失一次10分。这不单独证明某个权重错误，但证明“固定预算”不等于严重度、修复成本或跨用例分数尺度已获校准，3分平局阈值也未因此获得人工质量等价的含义。
3. **双模型独立调用隔离了答案，没有证明误差独立。** K3 与 K2.6 不互看答案，能显式暴露一部分分歧，区间也避免把分歧伪造成完整分数；两者仍共享来源、rubric与相近任务解释，且同属 Kimi 系列。相关错误不是仅凭模型家族推测：正式评分 QA 已发现02/B两模型都漏掉“人均”转“户均”所需假设，01/B两模型都以局部边界说明为新增已完成团队成果背书。共同 yes 会形成完整合并判定，却仍可共同漏检；分歧区间覆盖的是观察到的分歧，不是统计置信区间，也不覆盖这些共同盲点。正式视觉仍只有K3单评，不能借内容双评称全分数获得独立核验。
4. **判据有效、判断正确、分数有用与人工偏好一致之间，尚未建立可验证的对应关系。** 本轮已把这些报告拆开，但分开统计并未解决测量目标之间的差异。局部视觉回归8/8标签命中时，理由仍有对象/数字误读，独立模型还会换一个缺陷key重复处罚同一遮挡；因此标签命中或JSON通过不足以代表证据归属正确。现有人工记录又缺同案独立复评，其整体偏好、修改成本与“加权二元项、3分以内持平”并非已验证同一测量目标。不能把不一致统一归咎于人工，也不能靠增加调用、强求共识或挑权重提高一致率。最终应分别交代来源QA缺陷、判定QA缺陷、完整/区间覆盖与人工参照，保留各自分母和限制。
